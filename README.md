# LLM Playground

A lightweight repository demonstrating **modern LLM application concepts** without requiring any paid API.

This project focuses on the workflow commonly used in GenAI applications:

* Writing prompts
* Receiving structured JSON output
* Parsing and validating responses in Python

The implementation is intentionally **API-free and runnable offline**, making it easy for recruiters, mentors, and peers to test without setup costs.

---

## Features

* Prompt engineering example
* Simulated LLM JSON response
* Structured output parsing using Python
* Clean, beginner-friendly code
* No external API required

---

## Tech Stack

* Python
* JSON parsing
* Prompt engineering concepts
